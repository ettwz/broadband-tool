# 产品范围

doc_id: P01

面向家庭网络排障：看清当前连接、比较 Wi-Fi 信号与信道、区分局域网性能和公网体验、执行常用诊断。默认 Wi-Fi，支持系统已识别的 USB-C 转 RJ45 网卡。普通功能不依赖 root、越狱、Termux 或额外付费工具。

用户已增加 Android 可选高级模式：按网卡抓包、ARP / DHCP 排障、当前网络系统 DNS 缓存清理、USB 有线网络临时配置。设备获取 root 的方式假设为 KernelSU Next；本应用通过 Root 模式 Shizuku 授权访问。详见 [R06](../research/root-access.md)。不扩展到 iOS 越狱、弱网、防火墙、PPPoE 或 Wi-Fi 监听。

## 本轮完成标准

1. 11 项原始需求及 R12–R15 四项高级扩展都有规格、平台可行性、验收条件和开发任务。
2. 公网测速分别检查 API、可集成二进制及网页方式，记录证据与不确定性。
3. 共享架构保留 iOS 接入边界，不把 Android 系统对象散落在界面中。
4. 文档有索引、任务依赖、目录所有权和 agent 交接要求。
5. 验证文档链接、任务依赖、需求覆盖及 GUI 与规格一致；只做文档和静态渲染，不创建应用代码、原型工程或安装包。

## 第一期产品目标

Android 建议最低 API 29；正式开发时锁定稳定 SDK / targetSdk 并满足当时发布渠道要求。仅 IPv4 的 IP 诊断传输；域名工具只选择 A 记录。无 IPv4 时 IP 连接工具明确不可运行，不改测 IPv6；高级抓包/ARP/DHCP 可以在尚未获得 IPv4 的物理接口上工作，ARP 为必要链路层辅助。Wi-Fi 扫描与 IP 协议无关，仍覆盖硬件可见的 2.4 / 5 / 6 GHz。

首页、Wi-Fi、测速、工具四个主入口。离线可用的局域网工具不要求互联网连接。无账号、无云端同步、无广告；历史保存在本机，可删除。Wi-Fi 图表在本产品内不设单独付费门槛（规划建议）。

“工具”内分基础/高级页签；高级状态和授权有独立页面，每项按能力开放。无 root 或未授权不影响基础功能。临时有线配置必须能预览、限时、恢复，并诚实显示权限丢失后的恢复未完成状态。

## 不能被悄悄缩小的要求

iperf3 客户端和服务端、Wi-Fi 两种图、网卡真实切换、telnet 交互、traceroute、dig 检查都属于一期目标。高级四项同属 Android 可选扩展交付目标；不能仅加入口就算完成。系统 DNS 清理在普通模式/iOS 仍受限，高级模式也要系统适配证据；iOS 周边 Wi-Fi 扫描限制不因 Android root 改变。详见 [D04](../delivery/risks.md)。

公网网页测速只有在选定网络与 IPv4 约束得到验证后，才算满足严格的一期目标。若做不到，需要用户明确接受例外；本轮只提出方案，没有替用户批准降级。
