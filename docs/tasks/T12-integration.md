# T12 Android 普通功能基线验收

doc_id: T12
status: planned
depends_on: [T06, T07, T08, T09, T10, T11]

必读：[P02](../product/requirements.md)、[D03](../delivery/acceptance.md)、[D04](../delivery/risks.md)、[A04](../architecture/lifecycle.md)。所有权：`tests/integration/`、`tests/fixtures/`、`docs/evidence/T12/`；跨功能修复由原 owner 或集成人完成，不擅自重写其他模块。

逐项执行 V01–V12，先看各模块证据是否覆盖正式代码路径，再补跨功能流程。覆盖当前目标 Android、最低支持版本、两家 OEM、USB 网卡、双网卡与 16 KB 页。所有没有设备的项目写未验，不能勾选。

运行正式工程的静态分析、定向测试和发布构建；检查原生库 ABI、许可证、安装包自包含、没有运行时下载工具依赖。实际安装打开主要页面，走 D03 完整链路，测试切后台、杀进程、再次启动和历史损坏。

验收：每项原需求有 evidence 路径与通过/失败/明确接受例外状态；没有权限错误被伪装为测量结果；停止后没有残留网络任务；UI 在窄屏/大字体/深色可操作。公网真实服务不用于自动循环回归。

产出：可安装测试包、构建信息、验收矩阵、已验证设备、已知限制、用户操作说明。包可安装不等于功能全完成。未经明确授权，不提交推送、签发生产凭据或上架；这些动作与测试包交付分别处理。

本任务验证普通功能基线。新增四项高级功能和 V13–V17 由 T20 汇总，完整 Android 普通 + 高级交付不能仅依据 T12 放行。iOS T13 仍可依赖此普通基线独立推进。
