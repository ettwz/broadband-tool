# ping、tcping 与 telnet

doc_id: F04 · 原需求 3

统一支持 IPv4 或域名；域名在所选网络解析 A 后显示实际目标。一次解析结果固定到该任务。表单使用结构化字段，不接受额外 shell 片段。诊断引擎随包提供，断开互联网后仍能检查局域网。[R03](../research/tools.md)

| 工具 | 默认参数 | 输出 |
| --- | --- | --- |
| ping | 10 次，1 秒间隔，2 秒超时，56 字节载荷 | 每包序号/RTT/TTL（可获取时），发送/接收/丢包，最小/平均/最大 RTT |
| tcping | 端口 443，10 次，1 秒间隔，2 秒连接超时 | 成功连接时间、拒绝、超时计数；关闭每次连接 |
| telnet | 端口 23，5 秒连接超时，UTF-8 | 可交互终端；输入、回显、滚动、复制、断开 |

高级范围：次数 1–1000、间隔 0.2–10 秒、超时 0.2–10 秒；ping 载荷 8–1400 字节；端口 1–65535。手机暂停/网络切换走取消流程，不补发积压探测。RTT 用单调时钟，单位 ms。

ping 只代表 ICMP 结果。超时提示“未收到回复”，不能直接判定设备关机。tcping 的 RST 表示目标或路径明确拒绝，不能算成功连接，也不能算无回复丢包；报告成功、拒绝、超时各自比例。

telnet 必须实现协议协商和交互，不以“TCP 23 连接成功”代替。处理 IAC、回显、换行、窗口尺寸与常用 ANSI；提供 Enter、Ctrl-C、Tab、Esc 触控按键。仅输入时提醒 Telnet 明文传输；不记录密码和默认会话正文。编码扩展以实际家庭设备测试决定，不承诺 SSH。

验收：受控 ICMP 响应/过滤，TCP 开放端口/拒绝端口/丢弃端口；telnet 测试服务协商后输入命令收到响应，中文、退格、长输出和断线。每种工具均验证绑定网卡、取消后无残留 socket，以及非法目标和注入样式输入被拒绝。RTT 测量结果不得使用 UI 帧间隔代替。
