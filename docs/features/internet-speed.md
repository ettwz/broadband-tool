# 公网测速

doc_id: F03 · 原需求 2

两个入口明确分开：“国内 · 中科大”和“国际服务 · Netflix FAST”。说明前者测试到指定高校站点，后者到 Netflix 分布节点，不保证出境或代表所有网站。API / 二进制优先调查结果见 [R02](../research/speedtest.md)，一期推荐官方网页候选。

用户点击后先展示服务名、将使用的网络和会产生较大流量的提示，再加载网页；FAST 可能自动开始测速，因此不能在用户打开“测速”页时预加载。Wi-Fi 或有线未选定、无 IPv4、权限不足时不启动。

页面容器保留原站主要操作和说明，具备加载、重试、停止并关闭、返回。允许所需 HTTPS 子资源；禁止任意页面调用本 App 的原生命令接口。新窗口、跳转到外部浏览器必须明确改变为系统网络语义，不能沿用当前网卡承诺。

出口显示三态：已验证使用所选 IPv4 网络 / 系统网络 / 未确认。**正式严格一期只能放行第一态**。后两态仅作为技术验证或经过 T00 接受的范围例外。清楚显示并不自动使它满足需求。

不要求抓取网页数值进入本机统一测速图；结果在原站查看即可。历史仅保存服务、时间、模式、结束原因，指标不可取得时为 null。网页结构变化不能导致崩溃或显示旧结果为本次结果。

错误涵盖站点无法加载、DNS/TLS 失败、PoW 不通过、限流、网络变化和不支持严格绑定。关闭后销毁会话并确认不再传流量；不能仅隐藏 WebView。

验收先用受控 HTTPS 测速页验证 Worker、多连接、DNS、双栈、接口切换与停止，再对两家真实站点各做有限手工兼容检查。不得把真实站点作为自动化压测靶；HTTP 200 不等于完整测速通过。若严格 IPv4 或出口验证失败，执行 T03 的失败分支，不能自动标完成。
