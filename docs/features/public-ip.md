# 当前公网 IPv4

doc_id: F08 · 原需求 6

功能等价于用户指定的 curl 查询模式。推荐端点为 `https://api-ipv4.ip.sb/ip`，发送可识别的应用 User-Agent；不要依赖首页对 curl UA 的特殊响应。依据 [S02-06](../research/sources-services.md) 与本轮 [O01–O03](../research/observations.md)。

请求通过选定 NetworkContext：该网络 DNS 解析、IPv4 连接、正常 HTTPS 证书验证；不更改全机网络。连接超时 5 秒，总超时 10 秒，响应上限 4 KiB；非 2xx、HTML、多个地址、IPv6、非法 IP 都返回明确错误。不要把重定向到未知主机后任意响应当作成功。

成功显示公网 IPv4、所用本地 IPv4、接口、服务名和时间；提供复制、刷新。结果缓存 60 秒但必须标“上次查询”，切换网络立即失效。网络不可用时旧值可供查看，不能继续标当前。

这个地址是服务观察到的请求出口，可能属于 NAT、VPN、代理或运营商；不能据此判断端口可入站、用户有独立公网 IPv4，或两张同 NAT 网卡一定走了相同路径。

验收：实际 API 一次手动查询与相同出口的 curl 对照；本地测试响应覆盖合法 IPv4、带换行、HTML、IPv6、429、超时和无网络；双网卡源地址/网络侧验证。不要在 CI 中持续请求第三方服务，也不要把公网 IP 原值写入默认诊断日志。
