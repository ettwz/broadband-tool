# Wi-Fi 检查

doc_id: F01 · 原需求 1 · Android 一期

包含“网络”“信号对比”“信道”三个页签。开始/暂停扫描按钮和最近扫描时间固定在页顶，滚动图表或列表时仍可操作；图表优先于当前连接信息和筛选器。网络列表展示 SSID、BSSID、RSSI dBm、频段、主信道、带宽、安全方式、最近发现时间；同名 SSID 用 BSSID 区分，隐藏 SSID 显示“隐藏网络”。支持名称/频段/信号筛选、信号排序、选取最多 8 个 AP 对比。参考 [S02-11](../research/sources-services.md)，不承诺复制参考产品的全部算法。

信号对比：X 轴时间，Y 轴 RSSI dBm，保留最近 10 分钟；显示当前、最小、最大和平均值。无新扫描结果不补假采样点；中断用缺口和时间标签表示。

信道：按 2.4 / 5 / 6 GHz 分页；X 轴按真实 MHz 计算、标注信道，Y 轴 dBm；峰值取 RSSI，横向范围按扫描报告的中心频率与信道带宽绘制。80+80 MHz 画分离区域，不能合成连续带宽。未知宽度标“未知”，不猜。6 GHz / 320 MHz 仅在硬件和 API 提供时显示。

信道图只缩放横轴，支持双指 1–8 倍缩放、放大后左右拖动，以及放大、缩小、复位按钮。纵轴范围和信号刻度固定为 −110～−20 dBm；上下滑动始终滚动页面。横轴曲线和刻度按可见频率范围重新绘制，扫描刷新保留视野，切换频段恢复全图；不能拖出所属频段。

这是**接收信号强度与频率重叠示意图**，不是射频频谱仪，不声称测得真实噪声、信道占用率或干扰百分比。若以后做信道推荐，要公开启发规则，并说明无法测量非 Wi-Fi 干扰。

扫描前请求准确权限；建议前台约 30 秒调度并遵循系统额度，接收系统可用扫描通知。拒绝、定位关闭、受限、旧结果分别显示；至少标明扫描时间与数据年龄。暂停保留图，恢复后取新结果。超过 2 分钟未见的 AP 标“未再发现”，不画成信号 0。

验收：已知 2.4/5 GHz AP；同 SSID 双 BSSID；信道 14 和频段边界；80+80 与未知宽度模拟输入；权限拒绝；连续超额请求不会伪造刷新。iOS 显示系统不支持原因及已连接信息入口，不展示模拟周边 AP。字段依据 [ScanResult](https://developer.android.com/reference/android/net/wifi/ScanResult) 和 [R01](../research/platform.md)。
