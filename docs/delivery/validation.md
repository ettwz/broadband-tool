## 仍需单独记录的专项场景

- [ ] 受控多跳拓扑、丢包/拒绝注入、双网络源地址对照。
- [ ] 多种 USB 网卡/扩展坞、拔插、同网段双接口及配置恢复。
- [ ] 6 GHz / 320 MHz、真实 80+80 MHz、长时间扫描和大量接入点。
- [ ] 手机上的 Private DNS 组合、撤权/服务终止、系统 DNS 跨网络隔离。
- [ ] 16 KB 页设备运行、更多 OEM 和 iOS 构建/设备验证。
- [ ] 有线配置写入及异常恢复；该功能尚未开放，不在“人工通过”范围内。
